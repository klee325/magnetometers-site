Australian Magnetometers in Schools

University of Tasmania outreach project supporting the teaching of geomagnetism, space weather and the aurora in schools.

Classes

  • Class 1: Magnetic Earth Models
  • Class 2: Measuring Earth's Magnetic Field with a Smart Device
  • Class 3: The Pop Bottle Magnetometer
  • Class 4: Aurora Forecasting
  • Class 5: The Solar Cycle
  • Class 6: Space Weather Events
  • Class 7: Magnetism in Rocks
